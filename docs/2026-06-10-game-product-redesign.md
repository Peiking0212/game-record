# 游戏产品风格改造设计方案

## 目标

将当前的"后台管理系统风格"改造为"游戏产品风格"，提升视觉调性、情绪价值和游戏氛围感。

## 改造范围与优先级

### P0 — 收益 70%（当天完成）

| # | 项 | 涉及文件 | 改动摘要 |
|---|----|---------|---------|
| 1 | Hero 深色化 + 数据预览 | `app/page.tsx` | 深色背景 `#0f172a`，标题下展示玩家年数据概览（累计游戏/时长/完成率/成就）；底部嵌入 4 张游戏封面墙 |
| 2 | 深色区域注入 | `app/page.tsx`, `app/games/page.tsx`, `app/profile/page.tsx` | 各页面至少一个深色区（`#0f172a` 或 `#111827`），用于 Hero / 数据面板 / 年度总结 |
| 3 | 游戏卡片封面化 | `components/games/game-cassette-card.tsx` | 卡片改为 3:4 竖版，封面占主体（放大 icon/cover），名称/状态/时长下置 |
| 4 | 数据卡片主次分明 | `components/home/home-stats.tsx` | "累计时长"做大主卡，其余做小副卡；加入"最常玩"徽章 |

### P1 — 收益 20%（次日完成）

| # | 项 | 涉及文件 | 改动摘要 |
|---|----|---------|---------|
| 5 | 个人主页焕新 | `components/profile/profile-client.tsx` | Steam 风格：等级系统、成就墙、最近沉迷、累计数据大面板；深色 Hero 头像区域 |
| 6 | 图表植入 | `app/report/`, `app/stats/` | 按需增加趋势折线图/年度统计图（使用 chart-visualization 或纯 CSS） |

### P2 — 收益 10%（最后完成）

| # | 项 | 改动摘要 |
|---|----|---------|
| 7 | 动效润色 | 数字滚动动画、卡片 hover 浮起增强、页面过渡 |

## 详细设计

### 1. Hero 深色化 + 数据预览（首页）

```
┌────────────────────────────────────────────┐
│   #0f172a (深蓝黑)                         │
│                                            │
│          🎮 游戏时光记录平台                │
│                                            │
│    ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐   │
│    │128款 │ │1632h │ │78%   │ │42个  │   │
│    │游戏  │ │时长  │ │完成率│ │成就  │   │
│    └──────┘ └──────┘ └──────┘ └──────┘   │
│                                            │
│    [进入游戏库]  [个人中心]                 │
│                                            │
│  ┌──┐┌──┐┌──┐┌──┐ (封面墙 - 半透明模糊)   │
│  │原││王││赛││艾│                         │
│  └──┘└──┘└──┘└──┘                         │
└────────────────────────────────────────────┘
```

- 数据来源：`getHomeStats()` + `getAchievements()`
- 封面墙：取 games 前 4 个有 icon 的，缩略图 + 渐变色铺底

### 2. 游戏卡片竖版封面化

当前 3:2 → 改为 3:4 竖版：

```
┌──────────┐
│  ┌─────┐ │
│  │游戏 │ │
│  │封面 │ │
│  │     │ │
│  └─────┘ │
│ 原神     │
│ 245h · 正在玩 │
└──────────┘
```

- 使用 `GameIcon` 组件渲染封面
- 无封面时使用 `defaultGameCover()` 生成的渐变色块
- 状态标记移至右上角小标签

### 3. 深色区域配色

| 用途 | 色值 |
|------|------|
| Hero 深色 | `#0f172a` |
| 数据面板背景 | `#111827` |
| 游戏卡片背景 (暗色模式) | `#1e293b` |
| 浅色主背景 | `#f8fafc` |
| 卡片背景 | `#ffffff` |
| 文字 (深色区) | `#f1f5f9` / `#94a3b8` |
| 文字 (浅色区) | `#1e293b` / `#64748b` |

### 4. 数据卡片主次

- 主卡（`col-span-2 md:col-span-2`）：**"累计游玩时长"**，用大字号（`text-5xl`）+ 🎮 emoji
- 副卡（`col-span-1`）：游戏数 / 成就数 / 完成率
- 加入"最常玩"徽章：按 playtime 排序的 top 1 游戏

### 5. 个人主页焕新（P1）

- 深色 Hero 区域：头像 / 玩家等级 / 头衔 / 统计
- 等级计算：`floor(sqrt(totalGames * 5 + totalHours * 0.5 + achievements * 10))`
- 成就墙：网格显示前 8 个成就
- 最近沉迷：取 playtime 最高的 3 个游戏

---

## 不变的内容

- 数据模型（`GameRecord`、`UserProfile`）不做结构性修改
- 现有的 settings / wishlist / review 页面不参与此轮改造
- 不引入新的外部依赖
